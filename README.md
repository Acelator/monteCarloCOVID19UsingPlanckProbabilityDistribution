This repository implements the algorithm for simulating the COVID-19 pandemic using Planck's probability distribution introduced by José Enrique Amaro and José Nicolás Orce in Biosystems Volume 218 from August 2022 ([Paper](https://doi.org/10.1016/j.biosystems.2022.104708)).

There are both Mathematica and a C++ (way faster) implementation based on the original authors Fortran code.
